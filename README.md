# Analog Clock

A simple analog clock built using **HTML**, **CSS**, and **JavaScript**. The clock displays hours, minutes, and seconds with rotating clock hands. The project is responsive and works well on both desktop and mobile devices.

## 🎯 Features

- **Analog Time**: Displays hours, minutes, and seconds with rotating clock hands.
- **Live Updates**: Time is updated every second.
- **Responsive Design**: Works on various screen sizes, from mobile to desktop.
- **Modern Style**: Dark-themed background with glowing clock hands for a clean aesthetic.
